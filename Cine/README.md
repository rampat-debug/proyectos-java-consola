🎬 Sistema de Cine en Consola – Java  
Proyecto académico desarrollado para practicar gestión de datos y Programación Orientada a Objetos.  
Simula el funcionamiento básico de un cine donde se pueden gestionar películas, sesiones y compra de entradas.

---

## 🎯 Objetivos de aprendizaje  
A través de este proyecto se trabajaron los siguientes conceptos:

- Programación Orientada a Objetos (POO)  
- Uso de colecciones (`ArrayList`, `HashMap`)  
- Encapsulamiento y clases (`Pelicula`, `Sesion`)  
- Gestión de relaciones entre objetos  
- Entrada y salida por consola (`Scanner`)  
- Control de errores con excepciones (`InputMismatchException`)  
- Validación de datos introducidos por el usuario  

---

## 📂 Funcionalidades  

- Añadir nuevas películas con nombre, director y duración  
- Crear sesiones asociadas a una película con hora y entradas disponibles  
- Evitar sesiones duplicadas a la misma hora  
- Mostrar únicamente las películas con sesiones disponibles  
- Comprar entradas para una sesión concreta  
- Actualizar automáticamente las entradas disponibles  
- Menú interactivo en consola  

---

## 🛠️ Tecnologías utilizadas  

- Java  
- Programación Orientada a Objetos  
- Colecciones (`ArrayList`, `HashMap`)  
- Entrada y salida por consola  
- Manejo de excepciones
